## V5.2 Certification Modal Update

Certifications keep the existing card format, but each card now opens an in-site modal.

Included credential modals:

- PMP® — Project Management Institute
- SAFe® 6 Agilist — Scaled Agile
- AWS Certified Cloud Practitioner — Amazon Web Services
- Scrum Master Accredited Certification — International Scrum Institute
- B.E. Electrical and Electronics Engineering — Bangalore University

The PMP, SAFe, and AWS modals include Credly verification links. The Scrum Master modal shows the certificate ID and issue date. No certificate image/PDF files are included, keeping the site clean.

## Run locally in VS Code

```bash
npm install
npm run dev
```

Open:

```bash
http://localhost:3000
```

Resume page:

```bash
http://localhost:3000/resume
```

## Upload to GitHub

```bash
git clone https://github.com/praveenkay/Personal-Site.git
cd Personal-Site
```

Copy all extracted V5 ZIP contents into the repo folder.

Then:

```bash
git add .
git commit -m "Add executive portfolio V5"
git push origin main
```

## Deploy

This project is regular Next.js. It can deploy to:

- Netlify
- Render
- Cloudflare Pages
- Vercel, if you choose later
- Any Node.js host

There is no Vercel-specific code in this version.
